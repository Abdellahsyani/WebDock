# Description
The inception project is about building a Docker based infrastructure where multiple services run in seperate containers.
Each service isolate from others, making it independent, while Docker networking allows them to communicate when needed.
Using Docker compose, the services are orchestrated together to create a complete and reproducible environement, with volumes
providing persistent data storage.

# Instructions
- To run the project it's enough to type
```make```

- shut down containers
```make down```

- rebuild all thing from scratch
```make re```

- clean all images exist images and containers
```make fclean```
